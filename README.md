# 🕵️ AI Research Squad

A multi-agent research system built with **CrewAI** that demonstrates how specialized AI agents can collaborate to research a topic, analyze findings, and produce a structured research report.

---

## 🎯 Project Goal

Given a research topic such as:

> **"RAG vs Long-Context LLMs for Enterprise AI"**

the system uses multiple specialized agents to:

1. Research information from the web
2. Analyze the technical aspects
3. Analyze enterprise and business implications
4. Synthesize the findings
5. Produce a final research report

### High-Level Architecture

```text
                         USER
                           │
                           ▼
                    Research Topic
                           │
                           ▼
                  ┌─────────────────┐
                  │  Web Researcher │
                  └────────┬────────┘
                           │
                           ▼
                  ┌─────────────────┐
                  │ Technical       │
                  │ Analyst         │
                  └────────┬────────┘
                           │
                           ▼
                  ┌─────────────────┐
                  │ Industry        │
                  │ Analyst         │
                  └────────┬────────┘
                           │
                           ▼
                  ┌─────────────────┐
                  │ Report Writer   │
                  └────────┬────────┘
                           │
                           ▼
                    FINAL REPORT
```

The project also contains a **CrewAI Flow** layer for application-level orchestration and state management can be separated from the individual Crews.

# 🔄 Task Pipeline

Each agent is associated with a specific task.

```text
Web Research Task
        │
        ▼
Technical Analysis Task
        │
        ▼
Industry Analysis Task
        │
        ▼
Report Writing Task
```

Tasks use **context** to provide information generated by previous tasks to downstream agents.

For example:

```text
Web Research Task
        │
        │ output
        ▼
Technical Analysis Task
        │
        │ output
        ▼
Industry Analysis Task
        │
        ├───────────────┐
        │               │
        ▼               ▼
                 Report Writing Task
```

This demonstrates how CrewAI tasks can form an information pipeline rather than functioning as isolated LLM calls.

# 🌊 CrewAI Flow

The project also contains a Flow implementation:

```text
flows/
└── crew_flow.py
```

The Flow introduces a higher-level orchestration layer.

### Crew

A Crew represents a team of agents performing work.

```text
Crew
 ├── Agent
 ├── Agent
 └── Tasks
```

### Flow

A Flow represents the application workflow.

```text
Flow
 │
 ├── Start
 ├── Execute Crew
 ├── Store State
 └── Listen for Completion
```

This separation is important when building more complex agentic applications.

# 🏗️ Design Principles

This project follows several important multi-agent design principles.

### 1. Specialized Agents

Instead of giving one agent every responsibility:

```text
One Agent
 ├── Research
 ├── Technical Analysis
 ├── Business Analysis
 └── Writing
```

we separate responsibilities:

```text
Researcher
Technical Analyst
Industry Analyst
Report Writer
```

This allows each agent to have a focused goal.

---

### 2. Task-Oriented Execution

Agents are assigned explicit tasks rather than receiving one enormous prompt.

```text
Agent
  +
Task
  ↓
Specific responsibility
```

---

### 3. Context Passing

Outputs from earlier tasks can become context for later tasks.

```text
Research
   ↓
Technical Analysis
   ↓
Industry Analysis
   ↓
Report
```

This creates an information flow between agents.

---

### 4. Separation of Concerns

The project separates:

```text
Agent Definition
        ↓
Task Definition
        ↓
Crew Orchestration
        ↓
Flow Orchestration
```

This makes the system easier to understand and extend.
